# 📚 CTET Quiz & Mock Test Platform

A modern and interactive **CTET exam preparation platform** built with **React.js, JavaScript, HTML5, and CSS3**.

This project provides students with a simple and engaging environment to practice CTET multiple-choice questions, attempt timed mock tests, receive instant results, and improve their exam preparation.

## ✨ Features

### 📖 Subject-wise Practice

Users can practice questions according to different CTET subjects.

Available subjects include:

- 🧠 Child Development & Pedagogy
- 🌍 Social Science
- 🇬🇧 English
- 🇮🇳 Hindi
- 🌐 General Knowledge

---

### 🎯 Practice Quiz

The Practice Quiz mode allows users to select a subject and practice MCQs.

Features include:

- Multiple-choice questions
- Random question selection
- Answer selection
- Score calculation
- Question explanations
- Interactive quiz interface

---

### 📝 Mock Test

A dedicated mock-test mode provides an exam-like experience.

The mock test includes:

- Questions from multiple subjects
- Randomized questions
- Fixed number of questions
- Countdown timer
- Automatic test completion
- Final score
- Performance feedback

---

### ⏱️ Countdown Timer

The mock test includes a countdown timer to create a real examination environment.

This helps students practice:

- Time management
- Question-solving speed
- Exam pressure handling
- Time-based decision making

---

### 📊 Result & Performance

After completing a quiz or mock test, users can see their performance.

The result section provides information such as:

- Total questions
- Correct answers
- Incorrect answers
- Final score
- Performance message

---

### 🎲 Random Questions

Questions are randomly selected during practice and mock tests.

This allows users to get different question combinations on different attempts.

---

### 🌙 Night Study UI

The application uses a dark, study-friendly interface designed especially for comfortable usage during night-time study sessions.

The UI includes:

- Dark black/navy-style background
- Glassmorphism cards
- High-contrast text
- Pink accent colors
- Subtle animations
- Falling white stars
- Modern responsive layout

---

### 📱 Responsive Design

The application is responsive and designed to work across different devices.

Supported screen sizes:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Tablet
